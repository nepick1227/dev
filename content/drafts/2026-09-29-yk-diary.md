# 지도에 검색을 붙이고 나서 다 뜯어고쳤다

지도 뼈대는 있었는데, 정작 가게를 "검색"할 방법이 없었어요. 그래서 카카오 장소 검색 API를 연동하기로 했는데 — 하루 만에 지도 화면을 통째로 다시 짜게 될 줄은 몰랐죠.

## 🔍 1. 검색을 붙이니 레이아웃이 안 맞았어요

### 1.1 API 연동 자체는 금방이었어요
`카카오 장소 검색 API 연동 및 지도 레이아웃 수정` 커밋에서 `app/api/kakao-search/route.ts`를 새로 만들어서 검색 기능을 붙였어요. 카카오 REST API 키를 서버에서만 쓰도록 프록시 라우트 하나 두는 정도라 여기까진 어렵지 않았어요.

### 1.2 문제는 결과를 어디에 보여주냐였죠
근데 검색 결과 목록을 지도 위에 올리려고 보니, 기존에 짜둔 레이아웃으로는 검색바랑 결과 리스트, 지도가 서로 겹치는 문제가 생겼어요. 뼈대 단계에서는 지도 하나만 생각하고 짰던 화면이라, 검색 UI가 들어갈 자리가 아예 없었던 거예요.

## 🗺️ 2. 결국 홈 화면을 전면 개편

### 2.1 MapView를 거의 새로 짰어요
그래서 다음날 바로 `홈 지도 화면 전면 개편`으로 들어갔어요. `MapView.tsx`를 큰 폭으로 고치고, 지도 위에 뜨는 정보들을 따로 관리하려고 `MapOverlay.tsx`를 새 컴포넌트로 분리했어요. `RankingSheet.tsx`도 거의 절반을 다시 썼고요.

### 2.2 핀 색깔도 이때 정했어요
`marker-recommend.svg`, `marker-neutral.svg`, `marker-not-recommend.svg` — 추천/보통/비추 3종 마커를 이때 처음 만들었어요. 검색을 붙이고 나서야 "아, 지도 화면은 이렇게 짜야 하는구나"가 보이더라고요. 처음부터 완벽하게 설계하기보다, 실제로 기능을 붙여보고 안 맞는 부분을 다시 짜는 게 훨씬 빨랐어요.

## 🌱 3. 그 김에 자잘한 것들도 정리했어요

같은 날 `개발용 시드 데이터 추가`로 가게 200개를 미리 넣어서 실제로 화면이 어떻게 보이는지 확인했고, `kakao.maps.Map에 getBounds 타입 추가`, `kakao.maps.event 타입 추가`처럼 타입 정의도 하나씩 채워나갔어요. 카카오맵 SDK가 타입을 다 안 주다 보니 필요한 것부터 그때그때 추가하는 식이었죠.

검색 하나 붙이려다 지도 화면을 다시 짜게 된 하루였는데, 덕분에 지금 홈 화면 구조의 기본 틀이 이때 잡혔어요 🙌
